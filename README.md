# yet_another_tracker

## Что это

PWA для учёта личных финансов с фокусом на скорость ввода: одна транзакция за пять секунд, нативное ощущение в браузере и на мобильном, аналитика расходов и доходов, напоминания через Telegram-бот. Версия v1 разрабатывается автором для личного использования; архитектура заложена с прицелом на будущий AI-слой (чат с финансовым ассистентом, "what-if" сценарии) и расширение аудитории в следующих версиях.

## Структура репозитория

Все ключевые документы лежат в корне репозитория.

- **README.md** — этот файл. Обзор проекта и карта документов; читается первым при входе в репозиторий или старте новой LLM-сессии.
- **PLAN.md** — единый план текущей версии: текущая позиция, эпики, стори, задачи, открытые вопросы. Читается LLM-оркестратором в каждой сессии; обновляется кодинг-агентом после каждой завершённой стори.
- **AGENTS.md** — операционные правила для кодинг-агентов: архитектурные инварианты, запреты, формат коммитов и PR, процесс работы по эпикам. Читается кодинг-агентом перед каждой задачей.
- **CLAUDE.md** — точная копия AGENTS.md для агентов семейства Claude (Claude Code, Claude Design), которые ищут файл с этим именем по умолчанию.
- **DESIGN.md** — UI/UX-контракт проекта: визуальный язык, компоненты, паттерны взаимодействия. Заглушка до эпика 2; наполняется по итогам груминга с Claude Design.
- **backlog.md** — функциональность, отложенная в v2/v3, и окончательно отклонённые идеи с кратким обоснованием. Читается только при принятии решений о новых эпиках или при возврате к ранее обсуждённой теме.

## Технологический стек

- **Фронтенд:** Next.js 15 (App Router), TypeScript, Tailwind CSS, shadcn/ui, Apache ECharts.
- **Бэкенд:** Next.js Route Handlers, Prisma ORM, PostgreSQL.
- **Аутентификация:** NextAuth с Google OAuth (v1).
- **Локальное хранилище:** IndexedDB (local-first, офлайн-ввод).
- **Уведомления:** собственный Telegram-бот.
- **Бэкапы:** Backblaze B2 + JSON-экспорт в Google Drive.
- **Аналитика:** типизированные `track()`-стабы в коде (внешний сервис не подключается в v1).
- **Инфраструктура:** Docker Compose + Caddy + GitHub Actions, развёртывание на VPS (2 vCPU / 4 GB RAM).
