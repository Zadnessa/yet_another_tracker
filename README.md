# yet_another_tracker

Персональное PWA-приложение для контроля cashflow с амбициями на скейл.

## О проекте

Это инструмент личного финансового контроля, который решает три задачи:

1. **Мгновенный ввод трат и доходов** — главный сценарий «потратил → ввёл за 5 секунд → забыл».
2. **Осмысленная аналитика** с возможностью прийти к action points, а не просто посмотреть на красивые графики.
3. **Контроль регулярных платежей** с подтверждением через Telegram-бота.

Приложение разрабатывается одним человеком (PM-владельцем) с помощью AI-агентов (Codex, Claude Code, Claude Design). Целевой пользователь v1 — сам разработчик. Архитектура готова к масштабированию, но контент и приоритизация — под автора.

## Статус

🟡 В стадии планирования. `PLAN.md` формируется автоматически на основе документов из `docs/`.

## Стек

- **Frontend:** Next.js 15 (App Router) + TypeScript + Tailwind + shadcn/ui
- **Charts:** Apache ECharts
- **Backend:** Next.js Route Handlers + Prisma + PostgreSQL
- **Auth:** NextAuth.js, Google OAuth
- **Notifications:** свой Telegram-бот
- **Infra:** Docker Compose + Caddy + GitHub Actions, VPS в Нидерландах

## Версии

- **v1** — фундамент и базовый функционал для повседневного использования автором.
- **v2** — AI-функциональность, расширенная аналитика, конвертация валют, дополнительные провайдеры авторизации.
- **v3+** — масштабирование (Common-режим UI, семейный доступ, нативные мобильные приложения, интеграции).
